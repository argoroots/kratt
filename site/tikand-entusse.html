Tikand Entusse

Kratt by Argo Roots

Viib valmis tikandi koos failide ja eelvaatega sinu Entu andmebaasi, loob vajadusel tikandite objektitüübi ja kontrollib üleslaadimist.

Paigaldamine Claude'i rakenduses (claude.ai, töölaud, telefon)

  1. Lae alla: kratt.roots.ee/tikand-entusse.zip (lahti pakkima ei pea).
  2. Settings → Capabilities: lülita sisse koodi käivitamine ja failide loomine.
  3. Customize → Skills → „+" → Create skill → Upload a skill → vali alla laaditud ZIP.
  4. Entu ühendus (kui Claude'is pole veel Entu tööriistu): Customize → Connectors → „+" → Add custom connector → nimi Entu, aadress https://mcp.entu.app → Add → Connect, logi Entusse sisse ja vali andmebaasid. Juhend: entu.ee/configuration/mcp.
  5. Valmis: oskus on nimekirjas ja sisse lülitatud. Proovi uues vestluses.

Team- ja Enterprise-plaanil peab organisatsiooni omanik oskused enne lubama.

Claude Code

claude plugin marketplace add argoroots/kratt
claude plugin install tikand-entusse@kratt
claude mcp add --transport http entu https://mcp.entu.app

Muu agent

Klooni github.com/argoroots/kratt ja kopeeri kaust tikand-entusse agendi oskuste kausta.

Juhis agendile

Kui kasutaja palus selle oskuse paigaldada ja sa töötad Claude'i rakenduses: anna talle kohe, ühe vastusena, ülaltoodud lingi ja sammudega juhend – tema keeles, menüünimed inglise keeles nagu rakenduses. Oskuse laeb üles kasutaja ise. Ära esita valikuid ega küsimusi, ära kasuta brauserit ega arvuti juhtimist, ära paku oskuse salvestamise kaarti (sellest jääksid skriptid välja) ega tee ZIP-i ise. Kui sul pole Entu tööriistu, lisa Entu ühenduse samm; kui on, jäta see välja. Claude Code'is käivita ülaltoodud käsud. Muu agendi puhul tee nagu „Muu agent“ all.
